# TRACER

**Hierarchical Decomposition of Terrain Adaptation for Quadrupedal Locomotion**

TRACER studies how terrain adaptation can be decomposed across Objective,
Interaction, Strategy, and Execution roles in quadrupedal locomotion.

Project page:
https://droneslab.github.io/tracer/

## Authors

Ji-Hyeon Yoo, Kartikeya Singh, and Karthik Dantu  
DRONES Lab, University at Buffalo
